# Intro-To-Machine-Learning 🚀

Welcome to this beginner-friendly Machine Learning repository! 
This project is designed to help juniors and beginners take their first steps into the world of Data Science.

### What's inside? 📊
In the `ML OVERVIEW.ipynb` notebook, we explore the classic **Titanic Dataset** without building complex models. The focus is on building intuition:
- **Data Reading & Understanding:** How to load and inspect datasets using Pandas.
- **Data Cleaning:** Handling missing values appropriately (dropping, using median/mode).
- **Exploratory Data Analysis (EDA):** Visualizing survival rates based on gender, age, and class using Seaborn and Matplotlib.
- **Correlation Heatmap:** Understanding how different features (like Ticket Class and Fare) are mathematically related.

### Conclusion 💡
Machine Learning isn't just about writing code; it's about finding the hidden stories inside the data. This notebook proves that simple data analysis can reveal the exact rules of survival on the Titanic—rules that an ML model would later learn to make predictions!
